# Настройка оформления

Основной файл: `lib/app/brand_config.dart`.

- `AppColors` — вся палитра: основной текст, кнопки, фоны, линии, ошибки.
- `Brand.fontFamily` — семейство шрифта.
- `Brand.heroTitle`, `sectionTitle`, `body`, `small` и другие текстовые роли — размеры, начертания и межстрочные интервалы.
- `Brand.gutter`, `pageWidth`, `headerHeight`, `controlHeight` — общие размеры.
- `Brand.controlRadius`, `panelRadius`, `tileRadius` — скругления.
- `Brand.logo`, `heroPhoto`, `heroSurface`, `founderPhoto` — фирменная графика.

Например, смена `AppColors.navy` изменит основные кнопки и связанные заголовки. `lib/app/theme.dart` применяет эти настройки к стандартным элементам Flutter. Новые буквальные цвета и размеры шрифтов в экранах запрещены тестом `brand_design_test.dart`.

После изменения файла нужна новая сборка. Для веб-версии достаточно отправить изменения в `main`: GitHub Actions проверит код и обновит Pages.

Фотографии и фоновые изображения меняются заменой самих файлов. Их внутренние цвета не перекрашиваются настройками палитры.

## Данные и материалы

Цены, публикация товаров, галереи и отзывы поступают из рабочего API Laravel. Подробные информационные блоки, составы и документы взяты из сайта и сохранены отдельно в `assets/content/product_stories.json`. Они обновляются импортом, описанным в README, и новой сборкой; изменение этих разделов на сайте само по себе не меняет уже установленное приложение.

Нижняя навигация сохранена как элемент мобильного приложения. Информационные ссылки меню пока открывают соответствующие страницы сайта в браузере. Проверка скриншотов веб-версии не заменяет окончательную проверку Android на устройстве.
